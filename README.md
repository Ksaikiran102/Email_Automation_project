# 📧 Python Email Automation

A simple Python project that demonstrates how to send emails using Gmail SMTP. This repository includes examples for sending a basic email, sending emails with a subject, and generating an OTP for email verification using Python's `smtplib` and `email` modules. :contentReference[oaicite:0]{index=0} :contentReference[oaicite:1]{index=1} :contentReference[oaicite:2]{index=2}

## 📂 Files

- **simplemail.py** – Sends a simple email using Gmail SMTP.
- **mailUsage.py** – Sends an email with a subject and message body.
- **otpmail.py** – Generates a random 4-digit OTP, sends it via email, and verifies user input.

## ✨ Features

- Send emails using Gmail SMTP
- Email subject and body support
- OTP generation using Python
- Email verification example
- Beginner-friendly Python code

## 🛠 Technologies Used

- Python 3
- smtplib
- email
- random

This project currently contains hardcoded Gmail credentials for demonstration purposes. Before sharing or deploying the project:
